# Finger Traveller

A left-hand warm-up for violin and viola by Zac Johnston.

**Students:** open the page at **https://taceted.github.io/Finger-Traveller/**

The page:
- shows each level as a path down the strings (E → A → D → G) and back up
- lets you pick finger pairs, close/wide spacing and hand frames, with note names
- plays the pattern with a moving highlight, adjustable tempo and click
- switches between violin and viola
- has a **Download** button (saves the page to use offline) and **Print** (A4 / save as PDF)

`Finger_Traveller.pdf` is the original printable chart.

## Levels
1. **Finger + Open** — 1-0, 2-0, 3-0, 4-0 (close / wide). Option: change fingers by string.
2. **Two Fingers** — 1-2, 2-3, 3-4, 1-3, 2-4, 1-4 (close / wide)
2A. **Double-stop Bridge** — E:1 → together → A:2
3. **Add the Open** — 2-1-0 / 0-1-2 in one hand frame
4. **Whole Hand** — 4-3-2-1-0 / 0-1-2-3-4 in one hand frame

**Variations:** separate bows, slur 2/3/4, hooked bows, change position, long-short / short-long, change fingers by string.

## Updating the page
Everything is in `index.html`. Edit it, commit, and push: GitHub Pages republishes within a minute or two.
Change the `VERSION` line near the top of the script so students can tell which copy they have.
